# Diseñar requisitos

1. Identifica la acción, sus datos y el estado anterior y posterior del préstamo.
2. Escribe criterios observables con ejemplos y fechas fijas. Cubre el préstamo duplicado y distingue el día de vencimiento del primer día de atraso cuando el cambio toca esas reglas.
3. Indica qué archivos cambiarían y qué decisión queda abierta. Devuelve el resultado al coordinador antes de implementar.
