# Coordinar la entrega

1. Abre una etapa con `disenador`, espera sus criterios y pásalos a `desarrollador`. Pasa el diseño y el resultado del desarrollo a `verificador`.
2. Si se detecta un defecto del programa, remite el caso reproducible al desarrollador y pide una nueva verificación del cambio.
3. Cierra con el resultado de cada etapa, los archivos afectados y el comando de pruebas observado. Cuando una etapa quede pendiente, registra su estado.
